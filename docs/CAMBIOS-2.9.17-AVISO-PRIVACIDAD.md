# Smart Hub 2.9.17 — Aviso de Privacidad Integral

Se reemplazó el aviso de privacidad incompleto por una versión autosuficiente.

Incluye:
- responsable y contacto;
- categorías de datos tratados;
- datos de tarjeta;
- ubicación GPS;
- finalidades;
- proveedores necesarios (Supabase, Clip, hosting y correo);
- conservación;
- eliminación de cuenta;
- acceso, corrección, oposición, limitación y revocación;
- seguridad;
- almacenamiento local y cookies técnicas;
- cambios al aviso.

El documento no contiene campos `PENDIENTE` ni referencias que obliguen al
usuario a consultar otro documento para entender cómo se usan sus datos.
