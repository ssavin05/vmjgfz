# Mapa 3D HQ + responsive

- Zoom ampliado hasta 6.5x.
- Pinch-to-zoom con dos dedos y doble clic para acercar.
- Pixel ratio dinámico según pantalla/GPU para reducir borrosidad.
- Etiquetas 2x de resolución sin agrandar su tamaño físico.
- Texturas de mayor resolución y anisotropía.
- Sombras de mayor resolución cuando el perfil lo permite.
- La escala del edificio sólo se recalcula al cambiar el tamaño/orientación de la pantalla; seleccionar o girar no lo deforma.
- Ajustes CSS para teléfono, tablet, escritorio y landscape.
